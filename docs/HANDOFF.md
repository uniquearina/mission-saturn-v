## Принятые правила (не нарушать)
- **Одна новая вещь в миссии**, лестница «образец → допиши → сам». Экран «Учимся» только там, где есть новое.
- **Голос читает ровно то, что написано на экране** (`speak(text)` → `sayable`). Озвучиваем только нужное для действия.
- **Встроенный голос ставит ударения неверно**, знак ударения не помогает. Решение — заменить слово (так уже убраны «перенеси», «подлети», «строке»).
- **Все тексты на двух языках** через `L()`. В английской версии ЦУП — это Houston.
- **Проверки миссий строгие:** засчитывать только правильный результат.
- **Никаких навязываний.** Фото — по желанию, кнопки «без» на равных.
- **Никаких личных данных у посторонних.** Почту нигде не просим, на сервер от обычных игроков не уходит ничего: ни почты, ни имени, ни фото. Не добавлять счётчики (Яндекс Метрика и т. п.) — это тоже персональные данные.
